# Jogo da Velha (Tic-Tac-Toe)

Projeto simples em HTML, CSS e JavaScript que implementa o clássico jogo da velha.

Como usar
- Abra o arquivo `index.html` no seu navegador (duplo clique ou arraste para uma janela do navegador).
- Clique em uma célula para jogar como X. Os jogadores se alternam entre X e O.
- O jogo detecta vitória e empate e destaca a combinação vencedora.
- Use o botão "Reiniciar" para começar uma nova partida.

Arquivos principais
- `index.html` — marcação da página.
- `css/style.css` — estilos responsivos.
- `js/script.js` — lógica do jogo.

Compatibilidade
- Testado em navegadores modernos. Funciona offline sem dependências.
